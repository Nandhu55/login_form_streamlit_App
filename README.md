# 🔐 Secure Authentication System (Streamlit + MySQL)

A full-featured **User Authentication System** built using **Streamlit** and **MySQL**, featuring user registration, login, session handling, dashboards, profile pages, animations, and settings management.

This project demonstrates how to build a modern UI-driven authentication app using Python with a relational database backend.

---

## 🚀 Features

### ✅ Authentication
- User Registration with validation
- User Login & Logout
- Session-based authentication
- Unique username & email enforcement

### 🎨 UI & UX
- Modern animated UI using custom CSS
- Gradient cards & dashboards
- Sidebar navigation
- Responsive layout

### 📊 Pages & Modules
- Home Dashboard
- User Profile
- Analytics Dashboard
- Settings Panel
- Activity Feed & Stats

### 🛢️ Database
- MySQL backend
- Automatic table creation
- Secure database connection handling

---

| Technology | Usage |

| **Python** | Core programming language |
